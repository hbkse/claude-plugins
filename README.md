# hbkse's Claude Code plugins

A plugin marketplace for Claude Code. Add it once:

```
/plugin marketplace add hbkse/claude-plugins
```

Then install what you want from it:

| Plugin | What it does | Install |
| --- | --- | --- |
| [anki](https://github.com/hbkse/anki-claude-mod) | Review your AnkiWeb decks above the prompt while Claude works | `/plugin install anki@hbkse` |

Plugins and mods run with your permissions. Read a plugin's code before installing it, or run
`claude plugin validate` on a clone to list what it does.
